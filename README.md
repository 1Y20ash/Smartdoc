# SmartDoc

**AI-Based Document Topic Modeling and Classification System** using LDA and Machine Learning.

SmartDoc is a Flask-based NLP application that will analyze uploaded documents, discover hidden topics using Latent Dirichlet Allocation (LDA), and classify documents using topic-based features and supervised machine learning.

## Planned Features

- PDF, DOCX, and TXT document support
- Text extraction and preprocessing
- LDA-based hidden topic discovery
- Topic distribution visualization
- Logistic Regression-based document classification
- Keyword and topic insights
- Web interface built with Flask
- Deployment on Render

## Technology Stack

- Python
- Flask
- NLTK
- Scikit-learn
- LDA
- Logistic Regression
- HTML, CSS, JavaScript
- Git and GitHub
- Render
